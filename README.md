🚗 BMW Car Sales Dashboard – Power BI Project

This project showcases an interactive Power BI dashboard built to analyze BMW car sales performance across models, regions, and time periods. The report provides a visually appealing and data-driven view of key metrics that help understand sales trends and customer preferences.

📊 Key Features

Total Sales Overview – Displays overall revenue, total units sold, and key performance indicators.

Model-wise Performance – Compares different BMW car models based on sales volume and popularity.

Region-wise Sales Analysis – Identifies high-performing regions and market demand distribution.

Time-series Trends – Tracks monthly and yearly sales growth patterns.

Interactive Filters – Allows slicing data by model, year, region, and category for deeper insights.

Modern UI Design – Clean layout, gradient visuals, KPI cards, and charts for easy interpretation.

🛠️ Tools & Technologies

Power BI Desktop

Power Query for data cleaning and transformation

DAX for calculated measures and KPIs

CSV/Excel dataset (sample dataset used)

🎯 Objective

The main goal of this dashboard is to help stakeholders quickly understand BMW’s sales performance and make informed decisions based on:

Top-selling models

Sales patterns

Market demand shifts

KPI comparisons
